# Работа над сайтом SMLT

Этот репозиторий содержит только публичный Vue-фронтенд. В нём не должно быть
паролей, токенов, адресов базы данных, файлов `.env` или серверных конфигов.

## Обычный порядок работы

1. Создай отдельную ветку: `git switch -c feature/название`.
2. Измени файлы в `src/` или `public/`.
3. Проверь сборку: `corepack pnpm run build`.
4. Открой Pull Request в `main` и коротко опиши, что поменялось.

Сайт выкатывается на VPS только после просмотра изменений владельцем. Не
добавляй внешние скрипты, аналитику или новые API без отдельного обсуждения.

## Что где находится

- `src/components/` — страницы и элементы интерфейса;
- `src/styles.css` — стили и мобильная версия;
- `src/api.js` — публичные запросы к API;
- `public/` — favicon и прочие статические файлы.
